CuffnCode — Host Simulation

Mini project pada fork Farmil23/CuffnCode — simulasi lapisan PC Host untuk sistem tekanan darah CuffnCode (retrofitted BP, IFAC Activity Fund).

GUI tidak berjalan di halaman web ini. GitHub Pages hanya menampilkan dokumentasi. Aplikasi python gui.py adalah program desktop Tkinter. Untuk penilaian visual: rekam layar GUI atau unggah video singkat ke Instagram Lab.

Menjalankan di komputer Anda

git clone https://github.com/Farmil23/CuffnCode.git
cd CuffnCode/Host-Simulation
pip install -r requirements.txt
python gui.py
python main.py

Arsitektur (konsep)

[Cuff + MPS20N0040D] → [AD620 + TLC2272] → [STM32 ADC]
                              ↓
                        [Host PC]
              Data-parallel filter (Pool)
              Distributed nodes A → B → C (Queue)

Isi program

  • GUI — simulasi inflate/deflate, telemetri AFE/STM32, grafik filter
  • Benchmark — waktu sequential / parallel / dynamic + verifikasi peak
  • Distributed log — [Node A], [Node B], [Node C]

Catatan speedup

Pada data simulasi kecil (~4800 sampel), Windows sering menampilkan speedup < 1 karena overhead spawn proses. Untuk laporan: jelaskan pola paralel yang benar (peak sequential vs parallel cocok) dan kapan speedup diharapkan naik (stream ADC lebih panjang / Linux).
