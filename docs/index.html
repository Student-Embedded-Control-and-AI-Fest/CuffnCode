CuffnCode — Host Simulation

Dokumentasi mini project CuffnCode (retrofitted blood pressure system). Fokus tim: pemrosesan sinyal di PC Host — komputasi paralel & sistem terdistribusi.

GUI tidak jalan di halaman web ini. GitHub Pages hanya menampilkan dokumentasi (HTML). Aplikasi GUI (gui.py) adalah program desktop Python (Tkinter) — dijalankan di laptop setelah clone repo. Untuk demo visual di web: gunakan video Instagram Lab (20–30 detik) atau rekam layar GUI.

Menjalankan GUI (di komputer Anda)

git clone https://github.com/Farmil23/CuffnCode.git
cd CuffnCode/Host-Simulation
pip install -r requirements.txt
python gui.py

Klik Mulai Simulasi di jendela aplikasi — diagram hardware + grafik SEBELUM/SESUDAH akan tampil.
