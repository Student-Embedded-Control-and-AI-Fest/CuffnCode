1. Deskripsi Proyek & Konsep Paralel

Proyek ini berfokus pada optimasi pemrosesan *batch* citra digital (pemberian efek filter Gaussian Blur tingkat tinggi) secara mandiri. Pemrosesan gambar secara konvensional (sekuensial) memakan waktu lama karena hanya memanfaatkan satu core CPU (*Single-Thread*), menyebabkan tumpukan antrean proses.

Solusinya diimplementasikan menggunakan arsitektur website lokal berbasis **Python Streamlit** dengan memobilisasi pustaka concurrent.futures.ProcessPoolExecutor. Sistem memecah beban array gambar dan mendistribusikannya secara asinkron ke seluruh *core hardware* prosesor yang tersedia.

2. Pengukuran Metrik Performa

Akselerasi performa komputasi dihitung secara matematis menggunakan rumus baku *Speedup*:

Speedup = T_sekuensial / T_paralel

Berdasarkan hasil pengujian langsung pada platform web dengan sampel data 15 gambar resolusi tinggi, didapatkan hasil komparasi durasi sebagai berikut:

Metode Eksekusi Waktu Proses (Rata-rata) Efisiensi Core
Sekuensial (Single-Core) 28.40 detik Rendah (1 Core aktif)
Paralel (Multi-Core) 7.10 detik Maksimal (Multi-Core aktif)
Kesimpulan Uji Performa: Sistem mencapai nilai Speedup sebesar 4.00x lipat lebih cepat saat berjalan pada mode komputasi paralel.
